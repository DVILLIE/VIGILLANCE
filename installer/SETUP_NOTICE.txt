bootstrap and compiler staging. It aborts during initialization; it does not
extract and execute the former Administrator script from temporary storage.

The normal Limited installer script can be used from a verified protected source
stage with protected system Python on PATH. It protects code and keeps data/config
private to the installed user. Highest is refused before installation changes.

Windows can ask for Administrator approval to launch this held wrapper. It does
not imply that application installation or field validation has succeeded.

Published 2.4.2 archives are unchanged. See docs/REPAIR_INSTALL_PRIVILEGE_BOUNDARY.md
for current staging, interpreter and migration requirements.

This is not an antivirus product. It does not turn Windows Defender off, and it does not add a Defender exclusion.

The setup file is unsigned. Windows SmartScreen may say it prevented an unrecognized app from starting. That warning is expected.

DVielle does not prove this PC is free of threats.

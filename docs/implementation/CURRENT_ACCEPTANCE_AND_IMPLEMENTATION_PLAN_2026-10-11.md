## Implementation sequence

1. Keep installed runtime identity and source snapshot distinct; bind every deployment to reviewed file hashes and independent inventory.
2. Keep the working hosted validation and exact hash locks. Artifacts contain remote test XML, GUI measurements and model provenance only; local assessment exports, local machine inventories and signing keys are excluded. Extend isolated acceptance coverage deliberately and verify actual artifacts independently.
3. Run isolated Windows network and interruption acceptance scenarios before broadening action authority. Record failures and restoration outcomes as first-class evidence.
4. Complete human accessibility and randomized workload acceptance; select performance budgets before evaluation.
5. Keep optional AI held until resources, isolation and evaluation pass. Maintain deterministic observation and conservative recommendations throughout.
6. Establish authenticated public update/publisher roots, key lifecycle, complete notices and install/uninstall pilots. Release only the exact independently verified artifact.

# Ten quantum-inspired DV concepts

Creative animated samples for selection, not application changes or quantum
computing/security claims. The existing chrome D and distinct inset sapphire V
are shared deliberately to preserve the brand identity. The thin infinity
paths are non-metallic; the surrounding geometry and motion differ.

| No. | Concept | Direction |
|---|---|---|
| 01 | Azure Infinity | Simple cyan figure eight, two orbit lights |
| 02 | Violet Entanglement | Crossed cyan/violet infinity paths, opposing lights |
| 03 | Foldspace Drift | Slowly tilting infinity, floating monogram |
| 04 | Aurora Circuit | Mint and violet paths with counter-moving lights |
| 05 | Quantum Lattice | Fine lattice geometry surrounding the infinity |
| 06 | Photon Wake | Moving lights with trailing particles |
| 07 | Split Phase | Parallel blue and amber infinity paths |
| 08 | Prism Gate | Fine prism surround with an additional traveling light |
| 09 | Stellar Vigil | Constellation details and gently floating DV |
| 10 | Zero Point | Minimal icy-white infinity and diamond geometry |

`gallery.html` includes all ten animations, static alternatives, a pause/play
control, and the operating-system reduced-motion preference. `board-1.gif` and
`board-2.gif` compare five options each; `concept-01.gif` through
`concept-10.gif` are individual previews.

Created with native Tk drawing and an existing image master. GIFs are captures
of the rendered preview canvas, not installed app screenshots. Each GIF is
decoded to check its dimensions/frame count, and differing frames are checked
for actual pixel movement. Both comparison compositions are visually reviewed.

Primary design references:
[Microsoft icon design](https://learn.microsoft.com/en-us/windows/apps/design/style/iconography/app-icon-design),
[Fluent motion](https://fluent2.microsoft.design/motion).

Source generator: `../quantum_ten.py`. No new runtime dependencies or external
paid services. The generated-image master is `../dv-infinity-master.png`.

# D'Vielle branding and device connection animation

The active repair checkout now displays **D'Vielle** with **Intelligent Vigilance**
as the primary tagline. The header also shows the requested alternate wording:
**or Vigilia — Always Watching.** The approved Quantum Key artwork is retained.
The header logo increased from 84 to 148 logical pixels.

The network illustration's four blue connections now have a strong layered
trembling effect, with fixed endpoints and moving intermediate points. This
is decorative animation, not measured traffic or device communication. Labels
continue to reflect actual observations. Rendering uses a bounded twelve canvas
lines; motion off removes the effect and hidden pages cancel their timer.

Display spelling was corrected in application/agent copy, primary product
documentation, installer display metadata and shortcut names. Import names,
class names, installation/data paths, service/task IDs, registry keys, executable
names and firewall ownership identifiers retain their compatible internal forms.
Historical source-linked audit records and archived design samples are retained.
No installer was executed and no resident service was replaced.

Validation includes real Tk widget checks for changing connection coordinates,
bounded canvas item counts, motion-off behavior, hidden-page cancellation, logo
size and tagline presence. Installer PowerShell files were parsed without running
them. The full regression run recorded 525 passes and five skips, with one
outdated installer-message spelling assertion. That assertion was updated to
the approved display name without changing the safety behavior. Tk event-loop reference:
https://docs.python.org/3/library/tkinter.html
